# Ezetimibe Edu - Tugas Biologi
Website edukasi Ezetimibe dengan gaya LOFY Editorial.

## Cara Menjalankan
1. Pastikan Anda memiliki Node.js terinstal.
2. Jalankan perintah berikut di terminal:
   ```bash
   npm install
   npm run dev
   ```
3. Buka `http://localhost:3000` di browser.

## Catatan Supabase
Ubah variabel di `.env.example` menjadi `.env.local` lalu masukkan URL dan Anon Key dari project Supabase Anda, dan jalankan migration SQL yang ada di folder `supabase/migrations/`.
